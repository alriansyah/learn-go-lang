    Application Configuration :
    - Setiap kita membuat aplikasi, pasti kita tidak akan meng-hardcode konfigurasi aplikasi di kode program kita. Misal konfigurasi koneksi ke database, atau yang sejenisnya
    - Hal ini dikarenakan, tiap tempat untuk menjalankan aplikasi yang kita buat mungkin akan berbeda konfigurasi nya, misal di komputer kita, di server atau di komputer orang lain
    - Artinya, aplikasi yang kita buat, perlu memiliki kemampuan untuk mengambil data konfigurasi dari luar aplikasi, agar isi konfigurasi bisa diubah-ubah secara dinamis

    Golang Viper :
    - Viper adalah salah satu Library untuk Golang yang populer untuk melakukan manajemen konfigurasi
    - Viper mendukung banyak jenis file konfigurasi, seperti JSON, YAML, env file, properties, dan lain-lain
    - https://github.com/spf13/viper
- Membuat Project : https://docs.google.com/presentation/d/10Hff_VEA7NwjI3Qow8vIDE1UqyuFb2JRChAFczkoMdg/edit?slide=id.g28c0111f790_0_277#slide=id.g28c0111f790_0_277
    Membuat Project :
    - Buat folder belajar-golang-viper
    - go mod init belajar-golang-viper

    Menambahkan Viper :
    - go get github.com/spf13/viper

    Menambahkan Testify :
    - go get github.com/stretchr/testify
- Membuat Viper : https://docs.google.com/presentation/d/10Hff_VEA7NwjI3Qow8vIDE1UqyuFb2JRChAFczkoMdg/edit?slide=id.g28c0111f790_0_287#slide=id.g28c0111f790_0_287
    Membuat Viper :
    - Untuk membuat Viper, caranya cukup mudah, kita bisa menggunakan function viper.New()
    - Seteleh membuat Viper, kita bisa menentukan dari mana kita akan mengambil konfigurasi
- JSON : https://docs.google.com/presentation/d/10Hff_VEA7NwjI3Qow8vIDE1UqyuFb2JRChAFczkoMdg/edit?slide=id.g28c0111f790_0_313#slide=id.g28c0111f790_0_313
    JSON :
    - Viper bisa digunakan untuk membaca konfigurasi dari file JSON
    - Sekarang kita akan coba membuat file JSON, lalu membaca isi konfigurasinya menggunakan Viper

    Mengambil Value : 
    - Untuk mengambil value yang sudah dibaca dari file yang kita tentukan, kita bisa menggunakan method GetXxx, sesuai dengan tipe datanya, misal GetString, GetInt, GetBool dan lain-lain
    - Jika kita ingin mengakses nested object pada JSON, kita bisa menggunakan . (titik), misal : app.name, database.host
- YAML : https://docs.google.com/presentation/d/10Hff_VEA7NwjI3Qow8vIDE1UqyuFb2JRChAFczkoMdg/edit?slide=id.g28c0111f790_0_317#slide=id.g28c0111f790_0_317
    YAML :
    - Selain JSON, Viper juga bisa digunakan untuk membaca file dengan format YAML
    - Cara penggunaannya sama seperti ketika menggunakan JSON
- ENV File : https://docs.google.com/presentation/d/10Hff_VEA7NwjI3Qow8vIDE1UqyuFb2JRChAFczkoMdg/edit?slide=id.g28c0111f790_0_321#slide=id.g28c0111f790_0_321
    ENV File :
    - Viper juga bisa digunakan untuk membaca file dengan format Env
    - Di beberapa framework, kadang banyak yang menggunakan format ini
- Environment Variable : 
    Environment Variable :
    - Kadang saat menjalankan aplikasi, kita menyimpan konfigurasi menggunakan environment variable yang terdapat di sistem operasi yang kita gunakan
    - Secara default Viper tidak akan membaca data dari environment variable
    - Namun jika kita mau, kita bisa menggunakan method AutomaticEnv() untuk membaca dari environment variable
