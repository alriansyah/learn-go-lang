- Materi golang modules : https://docs.google.com/presentation/d/1nzeNb7w_F4_yA-9C95EYCrggObhQWt9WronMuhIG5LE/edit?slide=id.p#slide=id.p
- membuat module: go mod init nama-module
- Cara release versi go module di github :
    - membuat tag di gitnya
    - untuk tag disarankan dimulai dengan kata v "v1.0.0" : git tag v1.0.0, kemudian git push -u origin v1.0.0
- Menambah dependency : go get nama-module
- Upgrade versi module :
    - kita cukup buat tag baru di git sesui versinya
    - patikan sudah commit dan push perubahannya
    - git tag v1.1.0
    - git push -u origin v1.1.0
- Upgrade dependency :
    - Untuk upgrade dependency ke versi terbaru, kita bisa mengubah isi go.mod, lalu mengubah tag nya menjadi tag terbaru
    - Untuk mendownload versi terbaru, gunakan perintah : go get
